# Altered Carbon Shell v0.1.0

**Languages:** English · Українська · Русский

## Installation / Встановлення / Установка

Run the following command from a regular **non-root Ubuntu user with `sudo` privileges**. The installer is downloaded from the versioned `v0.1.0` Git tag and checked against the verified SHA-256 **before execution**.

Виконайте команду від звичайного користувача Ubuntu з правом `sudo` (не root). Скрипт завантажується з тегу `v0.1.0`, а його SHA-256 перевіряється **перед запуском**.

Выполняйте от обычного пользователя Ubuntu с правом `sudo` (не root). Скрипт загружается из тега `v0.1.0`, а SHA-256 проверяется **до запуска**.

```sh
sudo apt-get update && sudo apt-get install -y curl ca-certificates && curl -fL --proto '=https' --tlsv1.2 -o ac-shell-v0.1.0.sh https://raw.githubusercontent.com/alteredcarbonllc/ac-shell/v0.1.0/ac-shell-setup.sh && printf '%s  %s\n' '4925bdcba07bea531442347d1bcaa8159f3c48c17435140517d0635632be41f9' ac-shell-v0.1.0.sh | sha256sum -c - && sh ac-shell-v0.1.0.sh install --set-default-shell
```

After installation, sign out and sign back in if the default login shell was changed. **Caveat:** the `--set-default-shell` / interactive `chsh` step has not yet been tested end to end; it may request authentication.

Після зміни login shell вийдіть і увійдіть знову. **Застереження:** `--set-default-shell` / інтерактивний `chsh` ще не перевірено повністю; може знадобитися пароль.

После изменения login shell выйдите и войдите снова. **Ограничение:** `--set-default-shell` / интерактивный `chsh` ещё не проверен полностью; может потребоваться пароль.


## English

First public versioned release of Altered Carbon Shell, a reproducible **Ubuntu user-level Zsh environment** based on the audited Altered Carbon laptop configuration.

**Included:** POSIX `sh` installer; Oh My Zsh with `git`, `zsh-autosuggestions` and `zsh-syntax-highlighting`; Starship 1.27.0 with cyan hostname, yellow date/time and green two-line prompt; history settings; installed-version lock (`~/.config/ac-shell/versions.tsv`); repeatable installation; disposable QEMU/KVM lab; automated offline tests; MIT License; documentation in English, Ukrainian and Russian.

**Tests:** `OFFLINE_TESTS_OK` and `DOCS_TESTS_OK`; GitHub Actions across Ubuntu 22.04, 24.04 and 26.04; Ubuntu 24.04 VM `LAB_VM_PASS`; new-user pinned test `PINNED_LAB_PASS`; publicly downloaded tagged installer `RELEASE_TAG_LAB_PASS`. The tagged script matched `git show v0.1.0:ac-shell-setup.sh` byte-for-byte.

**Limitations:** complete CI network installation, other OS support, aarch64 integration, automatic upgrade/uninstall and full rollback remain untested or unsupported. The installer `--set-default-shell` / interactive `chsh` path and the exact README one-liner **have not been tested end to end**; login shell was changed in the guest using `usermod`. Run as a non-root Ubuntu user and review the script before installation.
