## 01 — Первичный аудит (30 октября)

- Обнаружены Ubuntu 26.04.1, Zsh 5.9, Oh My Zsh в ревизии `0eeaa529bb1442c2934930a5820f596e678458d4`, Starship 1.26.0.
- Обнаружены `fzf` 0.67.0, `zoxide` 0.9.8, Git 2.53.0, Python 3.14.4, `rg`, `fdfind`, `mosh`.
- Формат приглашения и активные плагины уточнены вторым аудитом. Личные dotfiles не копировались.

## 02 — Дополнительный аудит (30 октября)

- Активны `git`, `zsh-autosuggestions`, `zsh-syntax-highlighting`. `you-should-use` присутствует на диске, но не активирован.
- Starship: `$hostname$time$all`, дата `%d.%m.%Y %H:%M:%S`, две строки, голубой hostname, жёлтое время, зелёная стрелка.
- История: `HISTSIZE=50000`, `SAVEHIST=10000`, фильтр повторов, общая и расширенная история, `AUTO_CD`.

## 03 — Установщик v4 и отдельный пользователь (30–31 октября)

- Исправлено наследование `STARSHIP_CONFIG` / `ZDOTDIR` в офлайн-тестах.
- Новый пользователь `ac-shell-test` (UID 1002) первоначально имел `/bin/bash` и не входил в sudo.
- `sh test-shell.sh` завершился `OFFLINE_TESTS_OK`.
- `sh run-local-user-lab.sh`: установлены Oh My Zsh и оба плагина, подтверждён Starship **1.27.0**, записаны конфигурации и файл зафиксированных версий.
- Повторная установка повторно использовала репозитории и конфигурации; проверка выдала `VERIFY_OK`, итог — **`LAB_PASS`**.
- При запуске интерактивного Zsh из чужого Downloads-каталога Starship предупредил о тайм-ауте сканирования. После перехода в `/home/ac-shell-test` предупреждение исчезло.
- Пользователь изменил login shell и подтвердил `USER=ac-shell-test`, `SHELL=/usr/bin/zsh`, `CURRENT_SHELL=-zsh`, `HOME=/home/ac-shell-test`, Starship 1.27.0.

## 04 — Чистая VM (31 октября)

- На хосте доступны QEMU/KVM и 4 потока CPU; `/home` почти полон. Новую лабораторию разместили на корневом разделе в `/var/lib/ac-shell-lab`.
- Работающая VM Woodpecker/ejabberd не менялась и не останавливалась.
- Гость: официальный релизный cloud image Ubuntu 24.04, SHA-256 совпал (`ubuntu-24.04-server-cloudimg-amd64.img: OK`); 1 vCPU, 1 GiB RAM, 8 GiB sparse qcow2, SSH `127.0.0.1:22224`.
- Первая попытка SSH завершилась тайм-аутом при работе cloud-init. Последующий тест дождался настройки и подключился.
- В режиме **latest** установлены Starship 1.27.0 и Git-плагины, `verify` успешен. Вторая установка без `--latest` использовала прежние версии. Интерактивная проверка Zsh/истории успешна; результат — **`LAB_VM_PASS`**.
- Изначально `status` запускал `qemu-img info` без разрешения на параллельное чтение, вызывая предупреждение о блокировке. В публичном VM-скрипте применён `qemu-img info -U`; исправление ещё не проверено на ноутбуке.
