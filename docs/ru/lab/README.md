# Дополнительные лабораторные сценарии

**Язык:** [English](../../../lab/README.md) · [Українська](../../uk/lab/README.md) · Русский

## Отдельный локальный пользователь

`run-local-user-lab.sh` использует заранее созданного пользователя Ubuntu `ac-shell-test` с **пустой конфигурацией** и уже установленными на хосте пакетами. Скрипт отказывается работать с ранее настроенным пользователем, не меняет login shell хоста и не запускает APT на хосте.

```sh
sh lab/run-local-user-lab.sh
```

## Чистая Ubuntu 24.04 в QEMU/KVM

Требуются `qemu-system-x86_64`, `qemu-img`, `cloud-localds`, SSH, curl, KVM, как минимум примерно 1,5 GiB MemAvailable и 10 GiB свободного диска (скрипт проверяет ограничения). Скрипт хоста работает только с `/var/lib/ac-shell-lab` и портом `127.0.0.1:22224`, **не удаляет диски и не останавливает чужие VM**. Не используйте, если каталог или порт заняты другой лабораторией.

```sh
sudo install -d -m 0700 -o "$(id -un)" -g "$(id -gn)" /var/lib/ac-shell-lab
sh lab/ac-shell-vm-lab.sh prepare
sh lab/ac-shell-vm-lab.sh start
sh lab/ac-shell-vm-lab.sh test
sh lab/ac-shell-vm-lab.sh status
```

Для мягкого выключения: `sh lab/ac-shell-vm-lab.sh stop`. Выключение асинхронно; проверяйте `status`. **Автоматической очистки нет**. Удаление дисков и образов — отдельное осознанное административное действие.

Скрипт сравнивает опубликованный Canonical `SHA256SUMS`, но **не** GPG-подпись файла; проверка подписи — будущая задача. Приватный SSH-ключ лаборатории остаётся в `/var/lib/ac-shell-lab` и никогда не коммитится в Git.

Первый SSH-вход может не получиться, пока cloud-init выполняет настройки. Действие `test` специально дожидается завершения cloud-init перед установкой.
