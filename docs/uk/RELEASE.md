# Контрольний список першого релізу

**Мова:** [English](../../RELEASE.md) · Українська · [Русский](../ru/RELEASE.md)

Анотований Git-тег `v0.1.0` і [GitHub Release](https://github.com/alteredcarbonllc/ac-shell/releases/tag/v0.1.0) уже опубліковано. Інсталятор із тегу пройшов лабораторну перевірку.

1. **Виконано:** створено публічний `alteredcarbonllc/ac-shell`, базовий код відправлено до `main`.
2. **Виконано:** перший і другий запуски GitHub Actions успішні. Офлайн-матриця перевіряє `ubuntu-22.04`, `ubuntu-24.04`, `ubuntu-26.04`; це не повне встановлення з мережі.
3. **Виконано:** власник обрав MIT License для коду проєкту. Ліцензії сторонніх залежностей слід поважати окремо.
4. **Виконано:** тести Ubuntu 24.04 VM `LAB_VM_PASS`, закріпленого режиму `PINNED_LAB_PASS` і встановлення з тегу `RELEASE_TAG_LAB_PASS` (без перевірки `chsh`).
5. **Виконано:** опублікований анотований `v0.1.0` на коміті `b88ed432da8f1264d6c7ae712a542cf90e63076a`. Скрипт побайтово звірено з тегом, SHA-256 `4925bdcba07bea531442347d1bcaa8159f3c48c17435140517d0635632be41f9`.
6. **Виконано частково:** інсталятор завантажено й встановлено з тегу під новим користувачем VM; `verify` та інтерактивний Zsh успішні. **Очікує:** повний однорядковий сценарій з `--set-default-shell` / `chsh` і встановленням відсутніх пакетів у чистій ОС.
7. **Виконано:** опубліковано [GitHub Release](https://github.com/alteredcarbonllc/ac-shell/releases/tag/v0.1.0). **Очікує:** синхронізувати його опис із [тримовними нотатками з командою та SHA-256](../../releases/v0.1.0.md), не змінюючи тег.
8. Записувати точні результати, збої та коміти в [журналі розробки](DEVELOPMENT_HISTORY.md).

Сценарій завантаження та встановлення з тегу перевірено; повний однорядковий сценарій з `chsh` ще не тестувався.
