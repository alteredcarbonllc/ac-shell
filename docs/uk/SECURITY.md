# Безпека

**Мова:** [English](../../SECURITY.md) · Українська · [Русский](../ru/SECURITY.md)

- Інсталятор працює від імені **непривілейованого цільового користувача**. `sudo` використовується тільки для відсутніх залежностей APT; не запускайте інсталятор від root.
- `--latest` **не є** автоматичним фоновим оновлювачем: для нового користувача він один раз визначає upstream-версії та зберігає їх. Для production рекомендовано перевірені зафіксовані випуски.
- Архів Starship перевіряється за SHA-256 з того самого GitHub-релізу через HTTPS; це **не** незалежне криптографічне підтвердження автора релізу. Git-ревізії Oh My Zsh та плагінів записуються й перевіряються.
- Завантажений через `curl` скрипт залишається виконуваним кодом: перевіряйте його та фіксуйте незмінний перевірений commit або реліз на критичних машинах. Команда з README спершу завантажує файл, а не використовує `curl | sh`.
- Існуючі конфігурації захищено, доки явно не вказано `--replace`. Перед змінами зберігаються копії конфігів та локального Starship. Повного транзакційного відкату немає.
- **Ніколи не додавайте в Git** приватні dotfiles, SSH-ключі, токени, TOTP, файли оточення, API-облікові дані, диски cloud-image або журнали із секретами.
- SSH лабораторної VM проброшено тільки на localhost; користувач із passwordless sudo існує **лише** у тимчасовій VM. Не відкривайте її SSH-порт у публічну мережу.
- Інсталятор не має перезапускати production-сервіси та не повинен залежати від identity, пошти чи VPN.

Якщо знайшли вразливість, до налаштування приватного каналу повідомлень зв'яжіться з власником репозиторію приватно через звичний захищений канал. Не публікуйте облікові дані чи матеріали експлуатації у відкритих Issues.
